# Design proposals

Structural changes to Muse Monitor (moving folders, changing public interfaces, the CSV schema or the
UI/session lifecycle) are proposed here before they are implemented — see [CLAUDE.md](../CLAUDE.md).

Each proposal states: the problem, the affected files, the options, risks, how compatibility is kept and
how the change will be verified. Separate what was confirmed in code or on a real device from hypotheses.
